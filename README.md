## 🇬🇧 English

DesktopPet lives on your desktop: it walks around, reacts to your mouse, sits on windows, and keeps you company while you work. It is also a small productivity toolkit.

### ✨ Features

| | |
|---|---|
| 🐾 **Interactive pet** | Walks, reacts, sits on window edges, can be dragged and thrown |
| ⏱ **Focus timer** | Sessions, daily goal, XP and levels |
| ✅ **Tasks** | Link a focus session to a task and track time spent |
| 📊 **Stats** | Last 7 days, best day, average, export to CSV / JSON |
| 💧 **Healthy reminders** | Water, movement, 20-20-20 eye breaks; auto-muted during focus or fullscreen apps |
| 📅 **Calendar** | ICS link for event reminders and a daily summary |
| 📝 **Quick notes** | Notes with reminders after a delay or at a set time |
| 🕌 **Prayer times** | Enter times manually and enable reminders |
| 🖥 **System monitor** | CPU, RAM and GPU popup; warns when usage stays high |
| 📋 **Clipboard history** | Last 30 text items, pin and search; skips password-manager content |
| 🎮 **Mini games** | Catch, Jump, Click counter, with XP rewards |
| 🛍 **Shop** | Spend earned points on hats, accessories and food |
| 🎨 **Themes & sounds** | Dark / light, accent color, per-event sounds, 12h / 24h clock |
| 🌐 **Languages** | Arabic and English |

### 📥 Install

1. Open the [latest release](https://github.com/Pr0fes0rx/DesktopPet-Releases/releases/latest).
2. Download `DesktopPet-Setup-x.y.z.exe` and run it.
3. If Windows SmartScreen appears, choose **More info → Run anyway**. The installer is not code-signed yet; make sure you downloaded it from this repository.

The app updates itself: **Settings → App updates**.

### ⌨️ Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + Alt + P` | Show / hide the pet |
| `Ctrl + Alt + T` | Start / stop the focus timer |

Right-click the pet or the tray icon for the full menu.

### 🔒 Privacy

Settings and data are stored locally in `%AppData%\DesktopPet`. The app only goes online to check for updates and, if you add one, to read your ICS calendar link. Clipboard history stays in memory unless you enable saving to disk.

| | |
|---|---|
| 🐾 **شخصية تفاعلية** | تمشي وتتفاعل وتجلس على النوافذ، ويمكنك سحبها ورميها |
| ⏱ **مؤقّت التركيز** | جلسات وهدف يومي ونقاط خبرة ومستويات |
| ✅ **المهام** | اربط جلسة التركيز بمهمة وتابع الوقت المستغرق |

| 📅 **التقويم** | رابط ICS لتذكير الأحداث وملخص يومي |

### 📥 التثبيت

1. افتح [صفحة أحدث إصدار](https://github.com/Pr0fes0rx/DesktopPet-Releases/releases/latest).
2. نزّل الملف `DesktopPet-Setup-x.y.z.exe` وشغّله.
3. إذا ظهرت نافذة SmartScreen اختر **مزيد من المعلومات ← تشغيل على أي حال**. ملف التثبيت غير موقّع رقمياً حالياً، فتأكد أنك نزّلته من هذا المستودع.

يتحدّث التطبيق تلقائياً من: **الإعدادات ← تحديثات التطبيق**.

### ⌨️ الاختصارات

| الاختصار | الوظيفة |
|---|---|
| `Ctrl + Alt + P` | إظهار الشخصية / إخفاؤها |
| `Ctrl + Alt + T` | بدء مؤقّت التركيز / إيقافه |

كليك يمين على الشخصية أو أيقونة الـ tray لعرض القائمة كاملة.

### 🔒 الخصوصية

الإعدادات والبيانات تُحفظ محلياً في `%AppData%\DesktopPet`. لا يتصل التطبيق بالإنترنت إلا للتحقق من التحديثات، ولقراءة رابط تقويم ICS إن أضفته. سجل الحافظة يبقى في الذاكرة فقط ما لم تفعّل حفظه على القرص.
