<h2 id="english">🇬🇧 English</h2>

DesktopPet lives on your desktop: it walks around, reacts to your mouse, sits on windows, and keeps you company while you work. It is also a small productivity toolkit.

### ✨ Features

| Feature | Description |
|---|---|
| 🐾 **Interactive pet** | Walks, reacts, sits on window edges, and can be dragged and thrown. |
| ⏱ **Focus timer** | Focus sessions, daily goals, XP, and levels. |
| ✅ **Tasks** | Link a focus session to a task and track time spent. |
| 📊 **Statistics** | Last 7 days, best day, averages, and CSV / JSON export. |
| 💧 **Healthy reminders** | Water, movement, and 20-20-20 eye breaks. Automatically muted during focus or when fullscreen apps are active. |
| 📅 **Calendar** | ICS calendar link for event reminders and a daily summary. |
| 📝 **Quick notes** | Notes with reminders after a delay or at a specific time. |
| 🕌 **Prayer times** | Enter prayer times manually and enable reminders. |
| 🖥 **System monitor** | CPU, RAM, and GPU popup with warnings when usage stays high. |
| 📋 **Clipboard history** | Last 30 text items, pinning, and search. Skips password-manager content. |
| 🎮 **Mini games** | Catch, Jump, and Click Counter, with XP rewards. |
| 🛍 **Shop** | Spend earned points on hats, accessories, and food. |
| 🎨 **Themes and sounds** | Dark / light mode, accent color, per-event sounds, and 12-hour / 24-hour clock. |
| 🌐 **Languages** | Arabic and English. |

### 📥 Installation

1. Open the [latest release](https://github.com/Pr0fes0rx/DesktopPet-Releases/releases/latest).
2. Download the `DesktopPet-Setup-x.y.z.exe` installer and run it.
3. If Windows SmartScreen appears, select **More info → Run anyway**. The installer is not code-signed yet, so make sure you downloaded it from this repository.

The app updates itself through **Settings → App updates**.

### ⌨️ Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + Alt + P` | Show / hide the pet. |
| `Ctrl + Alt + T` | Start / stop the focus timer. |

Right-click the pet or its system tray icon to open the full menu.

### 🔒 Privacy

Settings and data are stored locally in `%AppData%\DesktopPet`.

The app only goes online to check for updates and, if you add one, to read your ICS calendar link.

Clipboard history stays in memory unless you enable saving it to disk.
